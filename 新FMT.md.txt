# 新FMT
このファイルは、レポート生成時に Claude が遵守すべき **マスターFMT** の本文。
プロンプト内 `{master_fmt}` プレースホルダーは、このファイル全体の内容で置換される。

最終更新: 2026-05-07

---

## 表記ルール

- 「。」は使わない
- このレポートは運用者本人が書く月次報告書である前提で書く
  - 第三者として外から観察・推定する表現は使わない
  - 主語（運用者）は省略し、能動・断定形で記述する
- 文末表現
  - OK：〜である / 〜と考察 / 〜を実施 / 〜を継続 / 〜に直結
  - NG：〜と見られる / 〜と推測される / 〜が見られる / 〜といえる / 〜と思われる / 〜という構造である
- 「〜たい」「〜したい」は使わない（断定形に変換）
- 「〜となっております」等の過剰敬語は使わない
- 数値は必ず前月比とセットで記載する
- できるだけ簡潔な表現にする

## 考察の品質基準

- 数値の読み上げだけで終わらない
- 必ず「原因の仮説」と「次月の施策」をセットで書く
- 施策は具体的なコンテンツ・テーマまで落とす
- 自己評価コメントを書かない
  - NG例：「絶対値として高い実績である」「高水準を維持している」「〜と評価できる」「精度を担保している」
  - 数値の意味付けは「事実」と「因果仮説」に絞り、Good/Bad の良し悪し判定は見出し（◉Good / ◉Bad）に集約する
- Good/Bad 項目は独立した論点にする
  - 既に挙げた項目と同じ因果（同じ施策・同じ累積効果）の派生数値を、独立項目として立てない
  - 全体傾向を述べた後に、その傾向の一部に過ぎない数値を別項目として立てない
  - 内訳が必要な場合は、同じ項目内のサブ説明として記述する
  - NG例：「重点世代計561人」と並べて「女性25-34が81人」を別Goodにする
  - OK例：「重点世代計561人（内訳：男283 / 女278）」のように1項目内に統合
- Good/Bad 項目は各2〜3個を上限とする
  - 項目数が膨らむと各論点の重みが希薄化するため、最も影響度の大きい論点に絞る
  - 4個以上書きたくなった場合は、独立性が担保されていないか、上位の論点に統合できるかを再点検する

### NG / OK 例

- **NG**：「引き続き同様のコンテンツを継続する」
- **OK**：「窓回×外観系を週2本ペースで継続、タイトルに機能訴求を入れる」
- **NG**：「フォロワー数+200人で、絶対値として高い実績である」
- **OK**：「KPI100に対し+200人増加」
- **NG**：「ターゲット選定の精度が獲得の質を担保している構造が見られる」
- **OK**：「札幌市のリノベアカウントへ絞ったフォロー施策が、札幌市の実数値増加に直結」

## 過去レポートからの引き継ぎ

- 「当月の施策」セクションは、先月の正解レポートの「次月の対策」に書かれている内容を **原文用語のままそのまま転記** する
  - 運用者本人が書く月次報告書の前提に立つと、月をまたいだ用語の連続性が必要
  - 意味が同じでも翻案・要約はしない
  - 例外：あからさまに不自然な場合（誤字など）のみ最小限の修正
  - 言い換え可否を迷う場合は転記を優先する
  - NG例：先月「素材をアップで映した画像」→ 当月「アップショット」
  - OK例：先月「素材をアップで映した画像」→ 当月「素材をアップで映した画像」
- 上記以外（Good/Bad 考察、代表投稿の個別考察、次月対策など）は、当月数値からゼロベースで書く
  - 過去レポートの考察文言を流用しない

## 運用上のルール（提案してはいけないこと）

- **投稿本数の変更提案をしない**
    - フィード：月12本固定
    - リール：アドバンス契約は月12本、スタンダード契約は月4本
- **投稿時間・曜日の変更提案をしない**（17時台固定）
- **ストーリーズの運用変更提案をしない**
    - 投稿後にストーリーズで告知、リンクで HP 誘導がデフォルト運用
- **CV導線（資料請求・来場予約）の変更提案をしない**

## 考察してはいけないこと

### 共通

- フォロワー獲得は自社からのフォローアプローチ→フォロバ受領で成立する運用のため、フォロー実施数は運用者のシフト・予定で日次／月次に波がある
  - これを前提に、以下のNGを守ること

### フォロワー分析

- 月間純増数を「先月の純増数」と差分比較しない
  - 例：「先月+105 → 今月+208 で前月比+103人」のような表現は不可
  - 評価軸は「実数値の絶対水準」「ターゲット精度（エリア・年代）」に絞る
- 日次のフォロワー増減の波から施策効果・施策タイミングを考察しない
  - 日次のばらつきは運用者稼働都合に起因するため、時系列の波に意味付けをしない
  - 例：「月後半に伸びた→施策効果が後半集中」のような考察は不可
- 性別・年代の構成を施策の直接結果として因果づけない
  - フォロー施策がコントロールできるのは商圏（エリア・アカウントのジャンル）までで、性別・年代分布は商圏内ユーザーの属性反映
  - 事後の数値分布を「狙い通り獲得した」と書くのは結果論
  - NG例：「ターゲット世代を抑えたフォロー施策」「45-54男性を確保」「重点世代を狙った選定」
  - OK例：「商圏絞り込みの結果として重点世代計が561人」「商圏内属性分布の反映」
- 単月の数値変化を「当月施策の単月効果」として書かない
  - フォロー施策は月をまたいで継続している前提のため、月次結果は累積運用の反映として捉える
  - NG例：「今月のフォロー施策により25-34女性が81人」「自然流入が発生」
  - OK例：「継続運用の累積として25-34女性が81人」「1月以降継続しているフォロー施策の累積反映」

### リーチ分析

- 個別投稿スクショ・数値から確認できない範囲の推測をしない
  - 全投稿に共通する傾向（グリッド全体の表紙トーン・他投稿との比較での異色性など）は、プロフィールグリッドのスクショが依頼時点で受領済みでない限り書かない
  - NG例：「全投稿で素材アップカットを徹底」「グリッド全体がナチュラル基調」「他投稿との比較で異色」
  - 例外：プロフィールグリッドのスクショが依頼時に添付されている場合は、その範囲で観察可能な傾向として記述してよい
- 運用者の所感（`operator_memo`）に記載のない外部要因・運用都合を、要因として持ち出さない
  - 要因として書く前に、その要因が「数値データ」「投稿スクショ」「`operator_memo`」のいずれかに根拠があるかを確認する
  - 3つに根拠がない場合は書かない（AI側の憶測で外部要因を持ち出さない）
  - NG例（根拠なし）：「月末投稿による後伸び未反映が一因」「アルゴリズム変動の影響と推測」「季節要因による減少」
  - OK例（`operator_memo`に記載がある場合）：memoに「3月中旬以降、全社的にリーチが落ちており、アルゴリズム変動の可能性」とあれば、要因の1つとして反映してよい
  - 判断基準：根拠が3つのいずれにもない場合は、要因として書かずに省略する

### アカウント分析

- ストーリー単位の因果づけをしない
  - 「特定ストーリー『〜』がリンククリックを牽引」「3/10の文言が効いた」のような個別ストーリー起因の考察は、以下のいずれかが提供されている場合のみ書く
    - ストーリー単位のリンククリック数（運用者がアカウントログインして取得する数値のため、`operator_memo` または手動入力欄経由で渡される）
    - ストーリースクショ（依頼時添付）
  - データがない場合は集計レベル（プロフアクセス計 / WEBリンククリック計 / ストーリーリンククリック総数）の考察に留める
  - NG例：「3/10『理想のリノベーションを叶えます✨』が検討フェーズのユーザーをリンクへ後押し」
  - OK例：「リンククリック率は2.15%→2.52%へ改善。プロフィール到達後のアクション率は向上」
- ストーリーの文言・デザインの効果に踏み込まない
  - スクショ・内訳数値がない限り「『理想』訴求が機能した」「2段階訴求が高数値」のような効果の因果づけはしない
  - ストーリーのタイトル文字列は数値ファイルから取得できるが、それは「投稿された事実」であって「効いた」ことの根拠にはならない
- ハイライトの効果は、当月新設・改修した場合に限り集計レベルでの寄与可能性として書ける
  - NG例：「ハイライト経由でX件のクリックを獲得」（ハイライト経由の個別経由数値は通常データに含まれない）
  - OK例：「当月新設したハイライトが、訪問ユーザーの情報探索に応える導線として機能した可能性」

- セクション2：フォロワー分析
- セクション3：リーチ分析
